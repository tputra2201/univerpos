# Pengamanan data POS
- [ ] Pengaman server untuk penghapusan eksplisit, pembatasan penghapusan massal, dan arsip perubahan.
- [ ] Hapus inferensi penghapusan dari basis sinkron; lindungi perpindahan store dan data lokal kosong.
- [ ] Cadangan lokal otomatis saat Close Out/End of Day dan unduh arsip.
- [ ] Uji aturan keselamatan dan alur cadangan; periksa hasil aplikasi.
